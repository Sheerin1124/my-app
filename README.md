\# AI Meeting-to-Action Intelligence Agent

A split-screen dashboard that instantly organizes messy meeting content into a clean Summary, Key Decisions, and Action Items using AI.

## 🎯 What it does

- Paste a meeting transcript **OR** upload a meeting recording (video/audio)
- AI analyzes the content and generates:
  - 📋 **Summary** — quick overview of the meeting
  - ✅ **Key Decisions** — what was decided
  - 🎯 **Action Items** — tasks and next steps

## 🖥️ Features

- **Dual Input Modes**: Paste transcript text directly, or upload a meeting recording
- **Clean Dashboard UI**: Split-screen layout with color-coded output cards
- **Responsive Design**: Works across screen sizes

## 🛠️ Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes
- **AI**:(for summarization and analysis)
